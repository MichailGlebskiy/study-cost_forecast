# Инструкция к применению
1. У вас глобально должен быть установлен python
  (Напишите в консоль `python --version`, если выведется версия, значит все хорошо, иначе скачайте с официального сайта, при установке постаьте галочку "Добавить в путь")
2. Создайте виртуальное окружение
  В терминал выполните `python -m venv .venv`
  Затем ` .\.venv\Scripts\activate`
3. Установка библиотек
  В Терминале выполните `pip install .`
4. Запуск
  Из корня проекта выполните `python main.py`
